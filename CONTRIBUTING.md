# Contributing to NoteX

Open issues and pull requests in this repository. Describe the observed behavior,
expected behavior, and a minimal example using synthetic data. Do not attach
private documents, session files, backups, credentials, or complete user profiles.

Keep existing copyright and license notices. Add a dated modification notice
when changing upstream files and update MODIFICATIONS.md and CHANGELOG.md.
Contributions to NoteX are submitted under GNU GPL version 3; separately licensed
upstream components retain their existing notices and terms. No copyright
assignment or additional contributor agreement is required.

Build and run the native tests for editor changes. Run the Function List smoke
fixtures and validate a fresh portable package before releasing a binary.
Use isolated profiles and synthetic documents for testing.
